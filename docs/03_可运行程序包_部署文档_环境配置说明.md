- Node.js

## 3. 本地运行步骤

### 3.1 启动数据库

创建 MySQL 数据库：

```sql
create database agent_test default character set utf8mb4 collate utf8mb4_general_ci;
```

导入项目所需表结构。

启动 Redis：

```bash
redis-server
```

或使用 Docker 启动 Redis。

### 3.2 启动后端

进入后端目录：

```cmd
cd back\demo1
```

检查配置文件，确保 MySQL、Redis 和模型 API 配置正确。

启动：

```cmd
mvn spring-boot:run
```

后端默认地址：

```text
http://localhost:8080
```

### 3.3 启动前端

进入前端目录：

```cmd
cd frontend\relationship-agent-web
```

安装依赖：

```cmd
npm install
```

启动：

```cmd
npm run serve
```

前端地址以终端输出为准，常见为：

```text
http://localhost:8082
```

## 6. Dockerfile 示例

### 6.1 后端 Dockerfile

```dockerfile
FROM eclipse-temurin:17-jre

WORKDIR /app

COPY app.jar app.jar

EXPOSE 8080

ENTRYPOINT ["java", "-jar", "app.jar"]
```

### 6.2 前端 Dockerfile

```dockerfile
FROM nginx:alpine

COPY dist/ /usr/share/nginx/html/

COPY nginx.conf /etc/nginx/conf.d/default.conf

RUN chmod -R a+rX /usr/share/nginx/html

EXPOSE 80
```

## 7. Nginx 配置示例

```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
        add_header Cache-Control "no-store";
    }

    location ~* \.(js|css|png|jpg|jpeg|gif|webp|bmp|ico|svg|mp4|map)$ {
        try_files $uri =404;
        add_header Cache-Control "public, max-age=31536000, immutable";
    }

    location /api/ {
        proxy_pass http://backend:8080/;
    }
}
```

## 8. Docker Compose 启动

启动全部服务：

```bash
cd /opt/relationship-agent
docker compose up -d --build
```

查看状态：

```bash
docker compose ps
```

查看后端日志：

```bash
docker compose logs -f backend
```

停止服务：

```bash
docker compose down
```

## 9. 常用更新流程

### 9.1 更新前端

本地：

```cmd

npm run build
scp -r C:\Users\yanghao\Desktop\codex\relationship-agent-web\dist\* root@服务器IP:/opt/relationship-agent/frontend/dist/
```


服务器：

```bash
cd /opt/relationship-agent
docker compose build --no-cache backend
docker compose up -d backend
docker compose logs -f backend
```

## 11. 环境配置说明

需要配置：

- MySQL 地址、用户名、密码
- Redis 地址和端口
- DashScope API Key
- 模型名称
- JWT 相关配置
- 文件上传大小限制

示例：

```properties
spring.datasource.url=jdbc:mysql://mysql:3306/agent_test?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
spring.datasource.username=root
spring.datasource.password=${MYSQL_ROOT_PASSWORD}

spring.data.redis.host=redis
spring.data.redis.port=6379

langchain4j.open-ai.chat-model.base-url=https://dashscope.aliyuncs.com/compatible-mode/v1
langchain4j.open-ai.chat-model.api-key=${DASHSCOPE_API_KEY}
langchain4j.open-ai.chat-model.model-name=模型名称
```
