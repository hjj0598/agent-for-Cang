# 识忆承缘作品演示视频脚本

## 1. 视频目标

演示视频需要展示系统主要业务流程和核心智能功能，让评审专家能够快速理解：

- 系统解决什么问题。
- 系统有哪些主要功能。
- AI 技术如何参与实际业务。
- 系统是否可以真实运行。
- 系统是否具备完整工程能力。

建议视频时长：5 到 8 分钟。

## 2. 视频结构

### 第一部分：项目开场

建议讲解词：

```text
大家好，我们的作品是“识忆承缘”，这是一套面向个人关系管理场景的多模态长期记忆智能体系统。它不是一个简单的 AI 聊天工具，而是围绕人物档案、长期记忆、知识库、图片分析和关系维护建议构建完整业务闭环。
```

需要展示：

- 登录页
- 项目名称“识忆承缘”
- 线上访问地址

### 第二部分：用户登录与首页

演示步骤：

1. 输入账号密码登录。
2. 进入首页控制台。
3. 展示人物数量、知识库数量、聊天次数等统计。
4. 展示关系维护提醒和 AI 建议区域。

讲解重点：

```text
系统具备用户认证和数据隔离能力，用户登录后可以看到自己的关系数据、知识库数据和 AI 建议。
```

### 第三部分：人物档案与长期记忆

演示步骤：

1. 进入人物管理页面。
2. 新增或查看一个人物，例如 JJKING。
3. 进入人物详情。
4. 添加人物记忆，例如兴趣、偏好、重要日期。
5. 展示保存后的长期记忆。

讲解重点：

```text
人物档案是系统长期记忆的基础。用户可以围绕某个人持续补充信息，AI 后续回答时会结合这些上下文，而不是只看当前这一句话。
```

### 第四部分：知识库上传与检索

演示步骤：

1. 进入知识库页面。
2. 上传文件或手动新增知识。
3. 查看知识库列表。
4. 在 AI 聊天中提问与知识库相关的问题。
5. 展示 AI 回答中引用知识库内容。

讲解重点：

```text
系统会对知识文本进行切分和向量化，写入 Redis 向量库。用户提问时，系统先检索相关知识片段，再结合大模型生成回答，实现 RAG 知识增强问答。
```

### 第五部分：图片分析

演示步骤：

1. 进入图片分析页面。
2. 上传一张聊天截图或普通图片。
3. 选择分析模板。
4. 点击分析。
5. 展示 AI 返回的图片理解结果。

讲解重点：

```text
图片分析功能使系统可以处理非结构化视觉信息，例如聊天截图、图片文字和关系线索。这体现了视觉模型和关系记忆智能体的结合。
```

### 第六部分：AI 聊天与记忆调用

演示步骤：

1. 进入 AI 聊天页面。
2. 提问：“根据我对 JJKING 的记忆，给我一些关系维护建议。”
3. 展示 AI 回复。
4. 展示参考来源或上下文调用效果。
5. 点击历史会话，展示聊天记录保存和恢复。

讲解重点：

```text
系统的 AI 对话不是孤立问答，而是会结合人物记忆、知识库和聊天历史，生成更加个性化的回答。
```

### 第七部分：意见收集箱

演示步骤：

1. 进入意见收集箱。
2. 提交一条用户建议。
3. 查看自己提交过的意见。

讲解重点：

```text
意见收集箱用于收集用户反馈，支持后续产品迭代，体现系统的持续演进能力。
```

### 第八部分：管理员后台

演示步骤：

1. 使用管理员账号登录。
2. 进入管理台。
3. 展示用户列表、统计数据、反馈意见、操作日志。

讲解重点：

```text
系统不仅有普通用户功能，还提供管理员后台，便于系统运行维护和数据管理。
```

### 第九部分：Swagger 与部署

演示步骤：

1. 打开 Swagger 接口文档。
2. 展示接口列表。
3. 展示 Docker 容器运行状态。

讲解重点：

```text
项目具备接口文档、Docker 部署和线上运行能力，符合综合系统赛道对工程完整度的要求。
```

### 第十部分：总结

建议讲解词：

```text
识忆承缘通过多模态信息采集、长期记忆沉淀、知识库向量检索和 AI 关系维护建议，形成了从信息输入到智能决策的完整闭环。相比普通 AI 聊天工具，本系统更加注重真实业务场景、长期上下文和工程化落地。
```

## 3. 推荐演示路线

```text

  ↓

  ↓
人物管理
  ↓
人物详情和长期记忆
  ↓
知识库上传
  ↓
图片分析
  ↓
AI 聊天调用记忆和知识库
  ↓
历史会话
  ↓
意见收集箱
  ↓
管理员后台
  ↓
Swagger 接口文档
```

## 4. 视频录制注意事项

- 提前准备好演示账号。
- 提前准备好人物数据和知识库数据。
- 提前准备好一张适合演示的图片或聊天截图。
- 不要在视频中展示 API Key、服务器密码、数据库密码。
- 如果 AI 响应较慢，可以提前说明模型调用需要等待数秒。
- 演示时重点讲“智能体闭环”，不要只说功能列表。

## 5. 需要重点说出的创新表达

```text
识忆承缘不是简单的通用问答系统，而是将多模态识别、长期记忆、向量检索和主动关系维护建议结合起来，面向个人关系管理构建了完整的智能体工程实践。
```
