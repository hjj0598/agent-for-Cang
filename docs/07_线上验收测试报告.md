## 4. 前端静态资源检查

已检查前端容器目录：

```bash
docker exec -it relationship-frontend ls -lah /usr/share/nginx/html
docker exec -it relationship-frontend ls -lah /usr/share/nginx/html/js
docker exec -it relationship-frontend ls -lah /usr/share/nginx/html/css
```

容器内已存在：

```text
index.html
js/chunk-vendors.8bfd4ea4.js
js/app.f7f9ad48.js
css/app.b42c87d3.css
img
media
```

发现并修复的问题：

```text
css/js/img/media 目录权限为 700，导致 Nginx 访问静态资源时返回 404。
```

修复方式：

```bash
docker exec relationship-frontend chmod -R 755 /usr/share/nginx/html
```

建议在前端 Dockerfile 中永久加入：

```dockerfile
RUN chmod -R 755 /usr/share/nginx/html
```

## 7. 风险与处理

| 风险 | 影响 | 处理方式 |
| --- | --- | --- |
| 第三方模型 API Key 未配置 | AI 对话、图片分析不可用 | 检查 `.env` 中 `DASHSCOPE_API_KEY`。 |
| 视觉模型名称配置错误 | 图片分析失败，可能返回 `model_not_found` | 确认 `app.vision.model-name=qwen3-vl-plus`，重建并重启后端容器。 |
| MySQL 未启动 | 登录、记忆、人物数据不可用 | `docker compose restart mysql backend`。 |
| Redis 未启动 | 聊天记忆、向量检索可能不可用 | `docker compose restart redis backend`。 |
| 前端静态资源 404 | 页面空白 | 执行 `chmod -R 755 /usr/share/nginx/html` 并重建镜像。 |
| Nginx 反代路径错误 | 域名访问异常 | 确认域名代理到前端容器端口。 |
